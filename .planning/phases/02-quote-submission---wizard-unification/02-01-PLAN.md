<task type="auto">
  <name>Task 2: Create Zod quote schema with discriminated union</name>
  <files>Development/lib/schemas/quote-schema.ts</files>
  <action>
Create `Development/lib/schemas/quote-schema.ts` with:

1. **Import dependencies:**
   - `z` from 'zod'
   - `PROPERTY_TYPES` from './constants'

2. **baseQuoteSchema** - Common fields for all services:
   ```typescript
   z.object({
     // Contact info
     clientName: z.string().min(1, 'Name required'),
     clientEmail: z.string().email('Invalid email'),
     clientPhone: z.string().min(1, 'Phone required'),
     clientCompany: z.string().optional(),
     
     // Location
     address: z.string().min(1, 'Address required'),
     city: z.string().optional(),
     state: z.string().optional(),
     zipCode: z.string().optional(),
     
     // Property
     propertyType: z.enum(PROPERTY_TYPES),
     
     // Optional
     message: z.string().optional(),
   })
   ```

3. **efficiencyQuoteSchema** - Extends base with efficiency-specific fields:
   ```typescript
   baseQuoteSchema.extend({
     service: z.literal('efficiency'),
     propertySize: z.string().optional(),
     operatingHours: z.string().optional(),
     bookingDate: z.string().optional(),
     bookingTime: z.string().optional(),
     // NOTE: device_option and connectivity INTENTIONALLY OMITTED per WIZ-02
     // These are collected AFTER inspection, not during quote submission
   })
   ```

4. **consultingQuoteSchema** - Extends base with consulting-specific fields:
   ```typescript
   baseQuoteSchema.extend({
     service: z.literal('consulting'),
     timeline: z.string().min(1, 'Timeline required for consulting'),
     budget: z.string().min(1, 'Budget required for consulting'),
     projectDescription: z.string().min(1, 'Description required'),
     // NOTE: propertySize NOT required for consulting
   })
   ```

5. **advocacyQuoteSchema** - Extends base with advocacy-specific fields:
   ```typescript
   baseQuoteSchema.extend({
     service: z.literal('advocacy'),
     timeline: z.string().min(1, 'Timeline required'),
     budget: z.string().min(1, 'Budget required'),
     projectDescription: z.string().min(1, 'Description required'),
     claimType: z.string().optional(), // For future ADVO-11 enhancement
     distributorCompany: z.string().optional(),
     claimAmount: z.string().optional(),
     incidentDate: z.string().optional(),
     damageDescription: z.string().optional(),
   })
   ```

6. **quoteSchema** - Discriminated union:
   ```typescript
   export const quoteSchema = z.discriminatedUnion('service', [
     efficiencyQuoteSchema,
     consultingQuoteSchema,
     advocacyQuoteSchema,
   ]);
   ```

7. **Type exports:**
   ```typescript
   export type QuoteFormData = z.infer<typeof quoteSchema>;
   export type EfficiencyQuoteData = z.infer<typeof efficiencyQuoteSchema>;
   export type ConsultingQuoteData = z.infer<typeof consultingQuoteSchema>;
   export type AdvocacyQuoteData = z.infer<typeof advocacyQuoteSchema>;
   ```

<task type="auto">
  <name>Task 3: Create helper functions for inspection detection</name>
  <files>Development/lib/schemas/quote-schema.ts</files>
  <action>
Add to `Development/lib/schemas/quote-schema.ts`:

1. **isInspectionRequired** - Helper to determine if inspection needed:
   ```typescript
   import { INSPECTION_REQUIRED_TYPES, PropertyType } from './constants';
   
   /**
    * Determines if inspection is required for efficiency service.
    * Per Decision 1 in CONTEXT.md:
    * - hotel, building, industrial = REQUIRED (commercial-scale)
    * - residential, apartment, small-business = OPTIONAL
    * 
    * Only applies to efficiency service. Other services don't have inspections.
    */
   export function isInspectionRequired(propertyType: PropertyType): boolean {
     return INSPECTION_REQUIRED_TYPES.includes(propertyType);
   }
   ```

2. **getDocumentCategories** - Helper to get allowed categories for service:
   ```typescript
   import { SERVICE_DOCUMENT_CATEGORIES, ServiceType } from './constants';
   
   /**
    * Returns allowed document categories for a service type.
    * Per SVC-01: Filter categories to prevent confusion.
    */
   export function getDocumentCategories(service: ServiceType): readonly string[] {
     return SERVICE_DOCUMENT_CATEGORIES[service];
   }
   ```

3. **shouldShowBillUpload** - Helper for conditional rendering:
   ```typescript
   /**
    * Bill upload only shows for efficiency service.
    * Per EE-01 and success criteria #3.
    */
   export function shouldShowBillUpload(service: ServiceType): boolean {
     return service === 'efficiency';
   }
   ```

These helpers encapsulate business logic that all 4 wizards will use.
