<decisions_made>

- **RLS empty-result pattern:** When a role has no legitimate data in a table, use
  `USING (role_check AND FALSE)` rather than omitting the policy entirely.
  Omission → 400; explicit FALSE → 200 with empty array. Applied to technician/inquiries.
- **Resend initialization:** Client must be constructed inside the route handler, after the
  env-var guard. Module-level `new Resend(undefined)` throws at import time.
- **React key stability:** `key={phase.id}` (crypto.randomUUID at creation) preferred over
  `key={idx}`. The `idx` parameter is still needed in the map for mutation helpers
  (onChange sets `newPhases[idx].name`); only the `key` prop changed.
