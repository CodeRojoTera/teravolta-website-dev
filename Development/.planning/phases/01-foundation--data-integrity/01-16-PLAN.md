# Phase 01 Plan 16: Gap Closure - RLS Policy Fix for Public Document Uploads

## Objective

Fix critical RLS policy issue blocking public quote form submissions.

Purpose: Enable quote submission flow for public users with document uploads
Output: Updated API endpoint with supabaseAdmin document insert (RLS bypass)

## Background

**Issue Found By:** Phase 02 UAT testing (Test 3: Quote Submission)

**Problem:** Public users cannot submit quotes with bills because:
- Quote form uploads bills to `documents` table via `/api/create-quote`
- Public users are unauthenticated (no auth session)
- `documents` table has RLS enabled
- Current RLS INSERT policy blocks unauthenticated access
- Quote creation fails: "Failed to create quote"

**Root Cause:** RLS infrastructure was set up in Phase 1 but didn't account for public document uploads needed by quote form

**Decision:** Use Option A - Admin Bypass (supabaseAdmin with RLS bypass in API endpoint)
